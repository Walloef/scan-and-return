Shared sync

Connect every device to the same bin to share the catalog and ledger. Your key is stored only in this browser — never uploaded to the repo.

Not connected — data stays on this device.

Set it up (once)

  1. Sign up free at jsonbin.io, open API Keys, copy your Master Key.
  2. On the first device: paste the key, leave Bin ID blank, press Create new bin.
  3. Copy the Bin ID it shows. On every other device paste the same key + Bin ID and press Connect.

Note: anyone you share the key + Bin ID with can read and change the data. Fine for a demo; lock it down later with a scoped access key or real auth.
